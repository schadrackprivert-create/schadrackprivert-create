## Proyectos destacados

### [Distribuidora El Volcán](https://github.com/schadrackprivert-create/DSY1104_EP2_Distribuidora_El_Volcan)
Aplicación web académica con React y Bootstrap: catálogo, búsqueda, filtros, carrito, pedidos y administración local de productos. Incluye instrucciones de ejecución y pruebas con Jasmine y Karma.

**Alcance:** demostración frontend con almacenamiento local; sin pagos ni autenticación reales.

### [DriverLink — distribución Android](https://github.com/schadrackprivert-create/DriverLink-APK)
Versiones de prueba para Android, instrucciones de instalación y documentación del proceso de actualización y verificación de las descargas.

**Alcance:** distribución de APK para pruebas autorizadas; no contiene código fuente ni claves de firma.

### [Glopost — backend](https://github.com/schadrackprivert-create/backend-app)
Backend JavaScript con rutas de estado y verificación, configuración mediante variables de entorno e instrucciones de despliegue en Render.
